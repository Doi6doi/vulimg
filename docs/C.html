vulimg.h

Vulimg is a C and C++ library for low-level image manipulation through Vulkan.
The vulimg.h header is for the C part. It contains the VigImage type, some simple auxiliary types and correspondent functions.
If compiled with a C++ compiler, all the declarations are in the vigc namespace
