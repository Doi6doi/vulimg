Vulimg Usage

The usage scheme is the same in both C and C++ versions:
- Initialize the system by creating a Vulimg object
- Create Image object(s). You can load them from BMP or RAW files or fill the data directly through their address
- Use conversion or mainpulation functions of your liking
- You can write results as BMP or RAW files or just use the data through their address
You can find full examples in the test directory
